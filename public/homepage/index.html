What your frontend gets

Register a site in the developer portal and it gets its own isolated API on the same server those apps run on.

Register your site
User accounts
Sign-up, sign-in and sessions for your users, separate from every other app.
Your data, validated
Describe your collections in plain words; every value is checked against them before it is saved.
File uploads
Images and files stored with size limits and served back from the API.
Password reset
Reset emails that link back to your own site, rate-limited and single-use.
Live docs
Every route your app gets is listed with examples in the API reference.
Secure by default
Keys per app, rate limits, input sanitising and CORS for the sites you list. Nothing you send runs as code.

From localhost to production in three steps

  1. Register your site

    Create a free account and add your site. http://localhost works while you develop.

  2. Describe your data

    List the collections and fields you need, such as products with a name and a price. The routes are created for you.

  3. Call your API

    Use the publishable key from the browser, keep the secret key on a server, and add your live address when you deploy.

Start on localhost. Ship when you are ready.
